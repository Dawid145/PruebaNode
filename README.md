# Prueba Node - Solicitante-Compilador

Proyecto mínimo para probar que Solicitante-Compilador puede:

1. Recibir varios archivos.
2. Mantener su estructura.
3. Enviarlos a GitHub.
4. Ejecutar una GitHub Action.
5. Procesar un proyecto Node.js.

## Archivos

- `package.json` — configuración del proyecto.
- `server.js` — servidor Node.js mínimo.
- `README.md` — descripción del proyecto.

## Prueba local

```bash
npm install
npm test
npm start
```

Al abrir el servidor debería responder:

> Prueba Node recibida correctamente por Solicitante-Compilador.
